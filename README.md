# Portfolio BTS SIO SISR — Marvin

Site statique compatible avec GitHub Pages : aucune compilation ni installation n'est nécessaire.

## Fichiers
- `index.html` : accueil
- `parcours.html` : formation et compétences
- `realisations.html` : projets avec filtres interactifs
- `veille.html` : thèmes et sources de veille
- `bilan.html` : bilan et objectifs
- `assets/style.css` : design responsive
- `assets/script.js` : menu mobile, année automatique et filtres
- `assets/favicon.svg` : icône du site

## Publier dans le dépôt EXISTANT
1. Ouvrir https://github.com/Marvin-28/Marvin-28.github.io
2. Cliquer sur **Add file** puis **Upload files**.
3. Décompresser ce ZIP sur l'ordinateur.
4. Glisser-déposer le contenu du dossier `portfolio_bts_sio_sisr` dans GitHub : les cinq fichiers HTML, `README.md`, `.nojekyll` et le dossier `assets`. Ne téléverser pas seulement le ZIP.
5. Cliquer sur **Commit changes**.
6. Dans **Settings → Pages**, vérifier la branche `main` et le dossier `/(root)`, si c'est la configuration utilisée par le dépôt.
7. Attendre la fin du déploiement puis ouvrir https://marvin-28.github.io/.

## Avant de publier
Les exemples de projets et certaines parties du parcours/bilan sont des modèles à adapter. Remplace-les par tes travaux réels, ajoute les dates exactes et vérifie les informations personnelles. Ne publie pas de mots de passe, données de clients ni captures confidentielles.
