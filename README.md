# Portfolio BTS SIO SISR — modèle GitHub Pages

Ce modèle est un site statique en HTML/CSS/JavaScript, adapté à un portfolio étudiant en informatique.

## Personnalisation
1. Remplace `[Prénom Nom]` par ton nom d'affichage.
2. Complète la formation, les expériences, les compétences et les coordonnées.
3. Dans `realisations.html`, adapte les projets à ce que tu as réellement réalisé.
4. Ajoute ton CV PDF au dépôt si tu souhaites le partager.
5. Vérifie les textes sur ordinateur et téléphone avant publication.

## Publier avec GitHub Pages
1. Crée un dépôt nommé exactement `TON-PSEUDO.github.io` (remplace par ton identifiant GitHub).
2. Envoie tous les fichiers et dossiers de ce modèle à la racine du dépôt.
3. Ouvre **Settings → Pages**.
4. Dans **Build and deployment**, choisis **Deploy from a branch**, puis `main` et `/ (root)`.
5. Enregistre et attends quelques minutes. Le site sera normalement disponible à `https://TON-PSEUDO.github.io`.

## Arborescence
- `index.html` : accueil
- `parcours.html` : formation et compétences
- `realisations.html` : projets
- `veille.html` : veille technologique
- `bilan.html` : bilan et contact
- `assets/style.css` : design responsive
- `assets/script.js` : menu mobile et année du pied de page

Le contenu proposé est un exemple à personnaliser. Ne publie pas d'informations confidentielles ou personnelles que tu ne souhaites pas rendre publiques.
